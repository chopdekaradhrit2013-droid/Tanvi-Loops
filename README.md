# Tanvi Loops

Handmade crochet e-commerce prototype.

## Run locally

```bash
npm install
npm run dev
```

Open in Codespaces or Vercel. Place product photos in `public/products/`.

## Demo admin

- Email: `admin@tanviloops.com`
- Password: `admin123`

Data persists in the browser via localStorage.

Import the repo into Vercel for a live URL.
